# Contribuer au projet

1. Crée une branche pour une modification identifiable.
2. Explique dans le message de commit ce qui a été vérifié ou changé.
3. Relance `python 01_scripts/run_project.py` si le code, les données ou le protocole changent.
4. Relance `python -m unittest discover -s 01_scripts/tests -v` avant une fusion.
5. Ne modifie pas les résultats à la main et ne publie pas de données personnelles.

Chaque membre du groupe doit déclarer uniquement sa contribution réelle.

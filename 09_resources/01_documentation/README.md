# Un parcours progressif, de la donnée à l'interprétation

Chaque guide explique le choix scientifique puis les expressions Python utiles.
Les résultats viennent des tables exportées. Il n'est pas nécessaire de tout lire
avant de lancer le programme : commence par les données, le nettoyage et le split.

| 2 | [Dictionnaire](02_dictionnaire_variables.md) | Que signifie chacune des 36 variables ? |
| 3 | [Nettoyage et sélection](03_nettoyage_selection_transformations.md) | Que garder, exclure ou transformer, et pourquoi ? |
| 4 | [Valeurs manquantes](04_valeurs_manquantes.md) | Comment remplacer les absences sans fuite ? |

| 6 | [Modèles supervisés](06_modeles_supervises.md) | Pourquoi la base, la logistique et la forêt ? |

numériques derrière les figures dans `04_results/tables`. La section Python du
sujet met l'accent sur quelques méthodes approfondies : l'analyse s'y limite.
